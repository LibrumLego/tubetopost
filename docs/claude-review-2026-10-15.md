# Claude 검토와 토론

사용자 요청으로 Orca의 기존 Claude 세션에 `60e9f17..4846c48` 변경과 이름 검토를 전달했다. Claude는 실제 파일을 읽고 Critical/High 없음, 조건부 승인으로 판단했다. 검토 중 파일·DB·배포는 변경하지 않았다.

## 수용한 개선

- 고정 공개 글을 삭제·비공개로 바꾸면 probe가 함께 깨지는 문제: 랜딩에서 현재 공개 링크를 찾고 선택적으로 `DEMO_SLUG`를 지정하도록 변경했다. 글 0개면 글 검증만 skip하며 콘텐츠 준비 완료로 간주하지 않는다. sitemap에는 글이 있는데 랜딩 링크가 없으면 실패한다.
- 사이트 주소 누락 시 이전 도메인으로 조용히 fallback하는 문제: `NEXT_PUBLIC_APP_URL` 필수, http(s) origin 검증으로 변경했다.
- 공개 상세의 쿠키 의존: 익명 클라이언트로 통일했다. 현재 요청 시점 조회를 유지하므로 자동 CDN/static 캐시 개선을 주장하지 않는다.

새 probe의 글 교체·명시적 오래된 글·공개 0개·삭제된 지정 글·누락된 쇼케이스와 주소 검증을 포함한 테스트 6개가 통과했다. lint·프로덕션 빌드도 통과했다.

## 토론으로 바로잡은 판단

Claude는 아래 반론을 수용했다.

1. `Disallow: /app`은 `/post/app-foo`를 차단하지 않는다. slug 접두어 위험 지적을 철회했다.
2. 익명 클라이언트도 `connection()`을 호출한다. 쿠키 제거를 정적 캐시 개선과 동일시한 설명을 철회했다.
3. 이름 결정과 콘텐츠 검수는 병행할 수 있다. 한국어 이름이 글로벌 유입 포기를 뜻한다는 설명도 철회했다.
4. 같은 이름의 검색 결과는 식별성 약화 신호이며 실제 사업·상표 충돌의 증거로 단정하지 않는다. 커스텀 도메인만으로 검색 순위 개선을 보장하지 않는다.

합의한 방향은 콘텐츠 검수·측정과 코드 보강을 우선하고, 표시명은 사용자 결정으로 두며 구매 도메인은 이름 확정 후 연결하는 것이다. 현재 TubeToPost를 유지했고 ‘보다글’은 제안 상태다.

## 남은 이견

Claude는 sitemap keyset 전환을 1,000개에 가까워질 때까지 미뤄도 된다고 봤다. GPT는 기존 offset 루프를 같은 크기의 ID cursor 루프로 치환하는 정도여서 이번에 반영했다. 추가 인프라를 도입하지 않았고, 동시에 공개 상태가 바뀌는 동안의 완전한 DB snapshot을 보장한다고 주장하지 않는다.

다양한 영상의 검수 글 5개와 커스텀 도메인이 아직 미완료라는 상태는 양쪽 모두 동일하게 판단했다.

## 후속 콘텐츠 검수

그 뒤 사용자 요청으로 작업을 계속해 TED 영상 3개를 순차 변환하고 기존 TypeScript 초안과 함께 원문을 대조했다. Claude에게 [원고 4개](drafts/README.md)와 원문 파일을 전달해 추가 검토를 받았다. Matt Cutts·TypeScript는 사실 불일치 없음, Tom의 비교 구조 보강과 Julian의 부정/불평 관계 수정 제안을 받았다. 수정 후 공개했고 현재 검수 글은 원본 영상 5종이다. 커스텀 도메인과 표시명 확정은 여전히 미완료다.
