## 코드를 실행하기 전에 받는 피드백

이 영상은 TypeScript가 JavaScript에 타입 정보를 더해 코드 작성 중 피드백을 제공하는 과정을 소개한다. 존재하지 않는 변수를 사용하거나 예상과 다른 형태의 값을 다룰 때, 개발자가 IDE에서 문제를 더 일찍 확인하도록 돕는다는 설명이다.

영상에서는 `.ts` 파일에 JavaScript 코드를 작성하고 필요에 따라 타입 정보를 추가하는 흐름을 보여 준다. `tsc` 명령으로 코드를 JavaScript로 변환하며, 컴파일러 동작은 `tsconfig` 파일에서 설정할 수 있다고 안내한다.

[영상에서 확인](https://www.youtube.com/watch?v=zQnBQ4tB3ZA&t=0)

## 명시적 타입과 타입 추론

변수 이름 뒤에 콜론과 함께 `string`, `boolean`, `number` 같은 타입을 적는 것이 영상에서 소개하는 명시적 타입 표기다. 초기값으로부터 타입을 추론하는 방식도 함께 설명한다.

`any`는 타입 검사에서 벗어나는 선택지로 등장한다. 따라서 TypeScript를 쓴다는 사실만으로 모든 값이 엄격하게 검사된다고 읽기보다는, 어떤 타입 정보를 작성하고 사용하는지에 주목할 필요가 있다.

[영상에서 확인](https://www.youtube.com/watch?v=zQnBQ4tB3ZA&t=80)

## 객체를 설명하는 타입과 인터페이스

영상 후반에는 배열의 원소 타입, 사용자 정의 타입과 인터페이스가 나온다. 객체가 어떤 속성과 타입을 갖는지 표현하면 IDE가 그 정보를 바탕으로 자동 완성을 제공한다.

이 짧은 소개의 중심은 문법을 전부 익히는 것보다 타입 정보와 개발 도구의 연결을 이해하는 데 있다. 코드를 작성하는 순간 받을 수 있는 피드백이 무엇인지 살펴보는 입문 자료로 읽을 수 있다.
