# 개발자 테스트 계정

개발자 계정은 기존 로그인 계정의 서버 관리 plan을 `developer`로 지정한다. 별도 비밀번호를 만들지 않으며 기존 매직링크 로그인을 그대로 사용한다. 일반 가입 계정은 `free`, 월 3회로 유지된다.

0007 마이그레이션 적용 후 관리자가 다음 명령으로 기존 사용자 UUID를 지정한다.

```powershell
node scripts/set-developer-account.mjs <existing-user-uuid>
```

명령은 로컬 service role key를 사용해 해당 계정만 developer / 월 30회로 설정한다. 사용량을 초기화하거나 이력을 삭제하지 않는다. 브라우저에는 이 명령이나 서비스 키를 제공하지 않는다. authenticated 역할에는 profiles UPDATE 권한이 없어 사용자가 스스로 승격할 수 없다.

개발자 계정도 동시 1개, 월 30회 실행 시도, OpenAI 월 예약 비용 $1, 실행당 $0.05, 작업별 재시도 합계 $0.10 제한을 적용한다. 실패와 재시도도 실행 시도 한도에 포함되므로 성공 변환 30회를 항상 보장하지 않는다. 관리자 권한이나 다른 사용자의 데이터 접근 권한은 부여하지 않는다.

2026-10-14 현재 사용 계정을 개발자로 전환했다. 기존 성공 3회 기록을 보존하고 최신 품질 조정의 실제 변환 검증을 재개했다. 추가 TED 변환 2회와 TypeScript 변환 1회가 모두 완료됐다. 첫 TED 결과의 MRI 연구 단정을 발견해 지시를 보강하고 재배포했으며 두 번째 TED 결과에서 해당 단정이 사라진 것을 확인했다. TypeScript는 3개 섹션으로 생성됐다. 새 결과는 비공개로 유지한다. 날짜·수치·용어와 번역은 공개 전에 검토해야 한다.
