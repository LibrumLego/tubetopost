# 서비스 이름 검토 — 2026-10-15

결론: TubeToPost는 기능 설명에는 좋지만, 독립 브랜드로 키우기 전 변경을 권한다. 이번 작업은 이름 검토까지이며 서비스 표시명·GitHub 저장소·운영 URL을 임의로 바꾸지 않았다.

| 기준 | 판단 |
|---|---|
| 기능 전달 | Tube → Post로 영상의 글 전환을 쉽게 유추할 수 있음 |
| 발음·기억 | 영어권에서 이해하기 쉽지만 한국어 표기 ‘튜브투포스트’는 길다 |
| 확장성 | 영상 플랫폼을 넓힐 때 YouTube를 연상시키는 Tube가 제약이 될 수 있음 |
| 검색 구별 | 동일 명칭과 동일한 기능을 설명하는 서비스가 검색되어 불리함 |

검색 근거: [TubeToPost — YouTube transcripts to SEO blog posts](https://youtube-to-blog-optimizer.bestpaid.app/en), [동일 네트워크의 TubeToPost 소개](https://battery-health-tracker.bestpaid.app/saas/youtube-to-blog-optimizer/). 검색 색인에 같은 이름과 같은 기능 설명이 확인됐다. 상대 서비스의 사용자 수·매출·품질은 검증하지 않았다.

## 대안

| 후보 | 장점 | 약점 |
|---|---|---|
| 보다글 / Bodageul | ‘보던 영상을 글로’라는 뜻, 한국어 3음절, 특정 영상 플랫폼에 덜 묶임 | 영문만 보면 기능을 알기 어려워 부제 필요 |
| 클립글 / Clipgeul | 영상과 글의 결합이 직접적 | ‘클립글’이 일반 커뮤니티 표현으로도 쓰여 검색이 섞일 수 있음 |
| 담아글 / DamaGeul | 내용을 담아 글로 만든다는 인상 | 영상 변환임을 설명하는 부제가 필요함 |

추천은 **보다글 — 보던 영상을 읽는 글로**이다. 한국어 사용자를 우선하는 현재 서비스 방향에 잘 맞는다는 편집적 판단이다. 정확 일치 이름 검색에서 보다글·Bodageul의 뚜렷한 동일 업종 서비스는 확인하지 못했지만, 이것이 이름·도메인의 사용 가능성을 보증하지는 않는다. 도메인 등록 가능 여부와 상표 확인은 별도 단계다.

이름이 결정되면 표시명과 metadata를 함께 바꾼다. 구매한 도메인이 제공되면 Vercel이 해당 도메인에 실제 안내하는 DNS 레코드를 기준으로 연결하고, production 앱 주소·Auth callback·canonical·sitemap을 함께 점검한다. 아직 도메인을 구매하거나 유료 플랜을 변경하지 않았다.
