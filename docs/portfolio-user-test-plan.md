# 실제 사용자 테스트 준비

목표는 서비스를 실제 사용자에게 제공하고 피드백을 반영한 경험을 기록하는 것이다. 자막이 있는 YouTube 영상으로 변환·수정·공유를 시도할 자발적 참여자 5~10명을 목표로 한다. 목표치이며 실적이 아니다. 1차 기간은 7일을 제안한다.

2026-10-28 확인: 공개 데모는 사용 가능하지만 신규 변환 베타는 10월 19일에 종료됐다. 운영 Supabase 대시보드에서 사용자 지정 SMTP가 꺼진 상태를 확인했다. Supadata에서는 이번 주기 100크레딧 중 31개 사용, 69개 잔여, 11월 14일 초기화로 표시됐다. 대시보드 키의 끝자리와 로컬 키가 일치하고 로컬 키의 해시와 워커에 저장된 비밀값의 해시도 일치함을 확인했다. 로그인 메일 외부 수신과 공급자 결제 상한을 확인한 뒤 테스트 시작 시간을 정한다. 기존 계정·글과 이전 예약 내역은 보존한다.

## 비용과 중단

기존 제한을 초과하지 않는 1차 제안: 하루 OpenAI 예약 0.10달러, 전체 예약 0.30달러, 하루 Supadata 10크레딧, 전체 30크레딧, 동시 1개. 월 OpenAI 1달러, 월 Supadata 60크레딧 제한과 사용자별 한도도 유지한다. 영상 정보와 자막은 각각 1크레딧을 예약하므로 하루 최대 약 5회이나, 실패·재시도와 다른 한도로 실제 횟수는 줄어든다. 예약액은 청구액이 아니며 다른 앱·인프라 비용까지 차단하는 결제 상한은 아니다.

시작 전 공급자 계정의 잔액·결제 상한과 외부 이메일 수신을 확인한다. 한도 소진, 로그인 수신 실패, 반복 오류, 예상보다 높은 비용 또는 권한 문제가 발생하면 신규 모집과 변환을 중단한다. 잔액이 불명확하면 한도 증액이나 유료 요금제 변경을 하지 않는다.

## 모집

1. 지인과 팀원 중 강의·인터뷰 영상을 글로 정리하는 사람 3~5명에게 개별 안내한다.
2. 첫 참여자의 결과를 정리한 뒤 개발자·콘텐츠 제작자 커뮤니티에 테스트 글을 게시할 수 있다. 각 공간의 홍보·모집 규칙을 확인한다.
3. 실제 변환 가능 여부·종료 시각·한도를 공지한다. 날짜와 유입 경로를 기록한다. 무단 대량 메시지는 보내지 않는다.

### 모집 문구 초안

> 유튜브 영상의 자막을 편집 가능한 글로 정리하는 개인 프로젝트를 만들었습니다. 영상 하나를 변환하고 내용을 수정해보실 분 5~10명을 찾고 있어요.
>
> 자막이 있는 20분 이하 영상을 사용합니다. AI 초안이므로 중요한 내용은 원본과 대조해야 합니다. 처리량과 비용 한도가 있어 신규 변환은 조기 종료될 수 있습니다.
> 로그인은 이메일 매직링크 방식입니다. 메일 수신이 필요합니다.
>
> 로그인 없이 화면을 둘러보는 예시: https://tubetopost.vercel.app/demo
>
> 실제 변환 테스트 기간과 신청 방법은 로그인 메일과 처리 한도를 확인한 뒤 확정해 안내합니다. 사용해 보신 뒤 막힌 점이나 결과가 아쉬운 부분을 알려주시면 개선에 반영하겠습니다.

초안은 발송·게시하지 않았다. 시작 전에 기간, 로그인 방법, 영상과 데이터 처리 안내를 확정해 고친다.

## 측정

기간·모집 경로·관측 조건을 먼저 기록한다. 신규 가입 수, 변환 요청 사용자 수, 완료 사용자 수, 성공·실패 작업 수, 서로 다른 날짜에 다시 완료한 사용자 수를 구분한다. pnpm beta:report의 집계 기준과 날짜를 함께 기록하고 개발자 본인·테스트 계정은 별도 확인한다. 계정의 plan 값만으로 외부 참여자라고 단정하지 않는다.

피드백은 자발적으로 받고 필요한 만큼만 기록한다. 영상 URL·자막·이메일·자유 입력을 공개 보고서에 싣지 않으며 참여자의 결과는 동의 없이 공개하지 않는다. 공개 조회 통계는 고유 방문자 수가 아니다. 소수 표본의 비율은 불확실성이 크다.

참여 과제: 자막 있는 영상 1개 제출 → 초안과 원본 대조 → 제목 또는 본문 수정 → 원할 때만 공유. 완료하지 못했다면 마지막 단계와 불편한 점을 묻는다.

피드백은 모집에 사용한 기존 대화 채널에서 자발적으로 받는다. 참가자에게 영상 URL이나 글 전체를 보내달라고 요구하지 않고, 선택적으로 완료한 단계와 막힌 점을 묻는다. 커뮤니티 공개 모집의 답변 경로는 게시 전 해당 공간의 규칙과 연락 수단을 확인해 정한다.

### 피드백 질문 초안

1. 로그인을 마치고 변환을 시작할 수 있었나요? 막혔다면 어느 단계였나요?
2. 초안에서 영상과 달랐거나 수정하기 불편했던 부분이 있었나요? 민감한 원문이나 영상 주소는 공유하지 않아도 됩니다.
3. 같은 작업이 다시 필요할 때 이 서비스를 사용할 것 같나요? 이유는 무엇인가요?

### 사례 인용 동의 요청 초안

> 테스트 의견을 포트폴리오에 익명으로 요약해도 될까요? 직업·역할을 일반적으로 표시할 수 있으며, 이메일 주소·영상 주소·자막·글 원문은 포함하지 않습니다. 원하지 않으시면 공개하지 않습니다. 인용할 문장은 공개 전에 따로 보여드리겠습니다.

### 결과 기록 틀

- 기간·모집 채널과 초대한 인원, 자발적 참여자 수
- 가입·변환 요청·완료·실패·재사용의 각 정의와 계정 수, 확인하지 못한 부분
- 실제 비용과 예약액을 구분한 공급자별 사용량
- 공통으로 제기된 문제, 개선 전후와 확인 방법
- 한계, 편향 및 다음 실험. 참여자 원문과 개인정보는 동의 없이 공개하지 않는다.

## 시작과 중단 절차

새 테스트를 열 때는 하나의 DB 트랜잭션에서 시작 시각과 종료 시각을 함께 설정한다. 예약량 집계는 시작 시각 이후 기록을 기준으로 하므로 이전 시작 시각을 유지한 채 종료 시각만 바꾸지 않는다. 하루·월·총액과 동시 작업 한도는 유지하고 기존 예약 행은 삭제하지 않는다. 시작 직전 집계 기준선을 저장한다.

긴급 중단은 서비스 역할로 beta_limits.enabled를 false로 설정하는 방식이다. 재개 전 저장된 설정과 공개 상태를 확인한다. 동시 한도는 1을 유지한다. 중단 동작은 테스트 전 롤백 가능한 방식으로 검증하며 진행 중인 실제 작업의 결과를 중단 없이 보장한다고 표현하지 않는다.

최초 실사용 검증은 일반 계정에서 실제 수신한 매직링크로 로그인해 공개 자막이 있는 20분 이하 영상을 1개 처리한다. 시도 전후 공급자별 예약액·크레딧과 작업 상태를 기록하고, AI 요약과 원본을 대조한다. 총량과 일일 한도는 실패·재시도에도 소모될 수 있다. 테스트 참가자에게 보내기 전에 Gmail과 국내 메일 서비스 한 곳의 수신을 각각 확인한다.
