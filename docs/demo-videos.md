## 재검증

```sh
pnpm diag:transcript <video-id>
pnpm worker:check
```

진단 명령은 실제 자막 세그먼트가 파싱되어 `usable=true`인 경우에만 성공한다. 자막 없음·빈 응답·잘못된 자막은 종료 코드 1을 반환한다. 이 검사 성공만으로 LLM 생성 성공을 보장하지 않는다.

성공 후보가 확보되면 로그인한 앱에서 한 번 변환하고 `done`, 결과 편집, 공개 글의 비로그인 조회까지 별도 검증한다. 검증 전 성공 화면이나 실적을 만들어 제시하지 않는다.

## 남은 의존성

현재 자막 경로는 성공 후보 9개 중 0개다. 추가 후보 반복보다 별도 자막 공급 경로 또는 오디오 전사 워커의 설계·검증이 필요하다. Whisper fallback과 InnerTube ANDROID 경로는 구현되지 않았다.
