# 공개 베타 모집 글

게시 대상: 긱뉴스 Show. 사용자에게 게시 권한을 받았으나 현재 긱뉴스 로그인이 필요해 아직 게시하지 않았다.

제목: 유튜브 영상을 읽는 글로 정리하는 TubeToPost — 3일 무료 베타

링크: https://tubetopost.vercel.app

본문:

유튜브 영상 내용을 다시 찾아 읽거나 글의 초안으로 쓰고 싶어서 TubeToPost를 만들었습니다. 영상 URL을 입력하면 자막을 바탕으로 한국어 글 초안을 만들고, 편집·복사하거나 선택적으로 공개할 수 있습니다.

강의 복습, 자료 정리, 블로그 초안에 실제로 도움이 되는지 확인하려고 3일간 무료 공개 테스트를 진행합니다. 신규 변환은 2026년 10월 19일 오전 9시 4분(한국 시간)에 종료합니다. 서비스 첫 화면에도 종료 시각을 표시합니다.

- 자막이 있는 20분 이하 유튜브 영상
- 계정당 월 3회 무료, 결제 정보 입력 없음
- 작은 개인 프로젝트라 전체 하루 약 5건, 테스트 전체 약 15건 한정
- 실패 요청도 공급자 사용량을 소비해 실제 성공 건수는 더 적을 수 있음
- 동시 작업은 1개이며 혼잡하거나 한도가 소진되면 이용 제한
- 결과는 기본 비공개, AI 초안이므로 원본 대조 필요
- 종료 후 기존 결과 열람과 앱 내 의견 접수는 유지

써보셨다면 결과를 어디에 활용했는지, 가장 불편했던 점과 다시 쓸 생각이 있는지 앱의 의견란이나 이 글 댓글로 알려주세요. 추가 변환 관심 등록도 열어두었지만 아직 유료 상품을 판매하지는 않습니다.

## 운영 기록

3일 캠페인 전체 상한: 모델 API 보수적 예약액 $0.30, Supadata 30크레딧. 하루 상한 $0.10 / 10크레딧, 동시 1건. 기간 종료와 캠페인 총량은 DB에서 공급자 호출 전 강제한다. 일일 초기화는 UTC 00시(한국 09시)이며 72시간이 네 UTC 날짜에 걸쳐도 총량 상한은 늘어나지 않는다.

공개 직전 Supadata는 Free 100/mo 중 27 사용, 73 잔여였다. 무료 공급자 요금제나 결제 설정은 변경하지 않았다. 이 앱의 요청 예약 한도이며 계정 전체의 다른 서비스·키 사용이나 호스팅 비용을 통제하는 청구 한도는 아니다.
