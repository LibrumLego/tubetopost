# 수익 모델 토론 — 2026-10-16

사용자 요청에 따라 기존 Orca Claude 세션과 2회 의견을 교환했다. 수익 모델 검토만 수행했으며 광고, 결제, 요금제, 외부 홍보는 실행하지 않았다.

## 합의한 방향

- 영상→글 변환을 원하는 일반 사용자에게 무료 베타를 알린다. 현재 월 3회 제한을 유지한다.
- 첫 유료 실험은 추가 변환 크레딧팩이다. 반복 사용과 반복 구매를 관찰한 뒤 구독을 검토한다.
- 광고는 검수한 공개 콘텐츠에 방문이 쌓인 뒤 보조 수익으로 검토한다. 광고가 무료 변환 비용을 충당한다고 가정하지 않는다.
- 사용자 결과를 광고 목적으로 강제 공개하지 않는다.
- 무료 공개를 확대하기 전에 서비스 전체 사용량·비용 상한을 마련한다. 공급자 호출 전에 원자적으로 예약하고 자막 크레딧, 모델 비용, 동시 요청을 포함해야 한다. 이미 발생한 실제 비용의 합계만 확인하면 초과 사용을 막지 못한다.

## 토론에서 수정한 주장

Claude는 처음 구독 우선을 제안했으나 반복 수요가 아직 확인되지 않았다는 반박을 수용하고 크레딧팩 우선으로 수정했다. 미확인 공급자 가격·광고 승인 기간, 임의 가입자/매출 수치를 유료화 전제조건으로 삼는 주장도 철회했다. 적은 가입자 수만으로 수요 부재를 판단하지 않고 실제 노출과 전환을 함께 본다.

설문 응답과 실제 결제를 구분한다. 1~3명의 소규모 유료 파일럿은 초기 실험 규모이며 시장성 입증 기준은 아니다. 가격, 팩 크기, 예산, 성공률 임계값은 확정하지 않았다. 실패 뒤 예약 해제는 실제 공급자 소비분을 먼저 정산해야 하며 무조건 환원하면 안 된다.

## 다음 2주 제안

1. 방문 → 가입 → 첫 변환 성공 → 재사용 → 무료 한도 소진 흐름과 성공·실패 비용을 측정한다. 자막 크레딧 소진도 별도 기록한다.
2. 전체 비용·사용량 상한을 적용하고 소규모 유입부터 시작한다.
3. 한도를 소진하고 추가 사용을 원하는 사람에게 소규모 유료 팩을 시험한다. 실제 결제·환불·재구매와 결과물 활용을 관찰한다.
4. 반복 사용이 약하면 품질·용도를 개선한다. 팩 재구매가 나타나면 구독을 검토한다. 공개 콘텐츠 광고는 별도 트래픽과 정책 적합성을 확인한 뒤 결정한다.

## 공식 근거

- [Google 게시자 콘텐츠 없는 화면 정책](https://support.google.com/publisherpolicies/answer/11112688?hl=en): 콘텐츠 없는/저가치/행동 목적 화면의 광고를 제한하며, 수동 검토·큐레이션 없는 자동 생성 콘텐츠에 광고를 두지 말라고 명시한다. 검수 표시만으로 승인이 보장되지는 않는다.
- [AdSense 수익 안내](https://support.google.com/adsense/answer/9902?hl=en-GB): 수익은 방문량, 콘텐츠, 지역, 광고 설정 등에 따라 달라진다.
